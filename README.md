## 📚 Лабораторні роботи / Laboratory Works

### Лабораторна робота №3: Методи інтерполяції

**Мета:** Вивчити та реалізувати основні методи інтерполяції функцій.

**Реалізовані методи:**

1. **Метод Лагранжа** (`lagrange_interpolation`)
   - Класичний метод інтерполяції через многочлен Лагранжа
   - Використовує базисні поліноми
   - Складність: O(n²) для обчислення одного значення

2. **Метод Ньютона** (`newton_interpolation`)
   - Використовує розділені різниці
   - Більш ефективний для додавання нових точок
   - Включає функцію обчислення таблиці розділених різниць

3. **Кубічні сплайни** (`cubic_spline_interpolation`)
   - Використовує бібліотеку SciPy
   - Забезпечує гладку інтерполяцію
   - Краще підходить для великої кількості точок

**Приклад використання:**
```python
from lab3_interpolation import lagrange_interpolation, newton_interpolation
import numpy as np

x_points = np.array([0, 1, 2, 3])
y_points = np.array([0, 1, 4, 9])
x = 1.5

result_lagrange = lagrange_interpolation(x_points, y_points, x)
result_newton = newton_interpolation(x_points, y_points, x)

print(f"Lagrange: {result_lagrange}")
print(f"Newton: {result_newton}")
```

### Лабораторна робота №4: Чисельне інтегрування

**Мета:** Вивчити та порівняти методи чисельного інтегрування визначених інтегралів.

**Реалізовані методи:**

1. **Метод прямокутників** (`rectangle_method`)
   - Варіанти: лівих, правих та середніх прямокутників
   - Простий метод першого порядку точності
   - Похибка: O(h²) для середніх прямокутників

2. **Метод трапецій** (`trapezoidal_method`)
   - Використовує лінійну апроксимацію
   - Точність другого порядку
   - Похибка: O(h²)

3. **Метод Сімпсона** (`simpson_method`)
   - Використовує квадратичну апроксимацію (параболи)
   - Точність четвертого порядку
   - Похибка: O(h⁴)
   - Вимагає парної кількості відрізків

4. **Метод Монте-Карло** (`monte_carlo_integration`)
   - Стохастичний метод
   - Особливо корисний для багатовимірних інтегралів
   - Похибка: O(1/√n)

**Приклад використання:**
```python
from lab4_numerical_integration import simpson_method, trapezoidal_method
import numpy as np

# Інтегрування sin(x) від 0 до π
f = np.sin
a, b = 0, np.pi
n = 100

result_trapezoid = trapezoidal_method(f, a, b, n)
result_simpson = simpson_method(f, a, b, n)

print(f"Трапеції: {result_trapezoid}")
print(f"Сімпсон: {result_simpson}")
print(f"Точне значення: 2.0")
```
